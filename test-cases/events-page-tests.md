### Test Case ID: 1
**Title:** Перевірка додавання події до закладок авторизованим користувачем

**Priority:** Medium

**Preconditions:**
1. Користувач успішно авторизований у системі GreenCity.
2. Відкрита сторінка подій веб-застосунку.
3. У системі існує щонайменше одна подія, яка ще не додана до закладок цього користувача.

**Test Steps:**

| Step | Action                                                                           | Data | Expected Result                                                                                                                        |
|:-----|:---------------------------------------------------------------------------------| :--- |:---------------------------------------------------------------------------------------------------------------------------------------|
| 1    | Натиснути на іконку "Закладка" (Bookmark) у правому верхньому куті картки події. | - | Іконка "Закладка" змінює свій візуальний стан (стає залитою зеленим кольором).                                                         |
| 2    | Перезавантажити сторінку                                                         | - | Іконка "Закладка" відміченої події не змінює свого візуального стану.                                                                  |
| 2    | В панелі фільтрів активувати фільтр для показу подій, доданих у закладки.        | - | Список подій на сторінці успішно відфільтровується. Відображається лише та подія (або події), яка була відмічена закладкою на Кроці 2. |


### Test Case ID: 2
**Title:** Перевірка роботи пошуку подій за назвою

**Priority:** High

**Preconditions:**
1. Користувач успішно авторизований у системі GreenCity.
2. Відкрита сторінка подій веб-застосунку.
3. У системі створена та існує подія з назвою "Some Event".

**Test Steps:**

| Step | Action | Data | Expected Result |
|:-----| :--- | :--- | :--- |
| 1    | Натиснути на іконку пошуку (лупу) на панелі керування подіями. | - | З'являється текстове поле для вводу пошукового запиту. |
| 2    | Ввести в поле пошуку частину назви події. | `So` | Список подій динамічно відфільтровується. Відображаються всі події, що містять "So" у назві (включно з "Some Event"). |
| 3    | Дописати назву події повністю. | `Some Event` | Список подій оновлюється. Відображається лише та подія (або події), назва якої повністю відповідає введеному тексту "Some Event". |
