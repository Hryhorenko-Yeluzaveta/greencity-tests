### Test Case ID: 1
**Title:** Перевірка додавання події до закладок авторизованим користувачем

**Priority:** Low

**Preconditions:**
1. Користувач успішно авторизований у системі GreenCity.
2. Користувач знаходиться на сторінці подій (Events).
3. У системі існує щонайменше одна подія, яка ще не додана до закладок цього користувача.

**Test Steps:**

| Step | Action                                                                           | Data | Expected Result                                                                                                                        |
|:-----|:---------------------------------------------------------------------------------| :--- |:---------------------------------------------------------------------------------------------------------------------------------------|
| 1    | Натиснути на іконку "Закладка" (Bookmark) у правому верхньому куті картки події. | - | Іконка "Закладка" змінює свій візуальний стан (стає залитою зеленим кольором).                                                         |
| 2    | Перезавантажити сторінку                                                         | - | Іконка "Закладка" відміченої події не змінює свого візуального стану.                                                                  |
| 2    | В панелі фільтрів активувати фільтр для показу подій, доданих у закладки.        | - | Список подій на сторінці успішно відфільтровується. Відображається лише та подія (або події), яка була відмічена закладкою на Кроці 2. |


### Test Case ID: 2
**Title:** Перевірка роботи пошуку подій за назвою

**Priority:** High

**Preconditions:**
1. Користувач успішно авторизований у системі GreenCity.
2. Користувач знаходиться на сторінці подій (Events).
3. У системі створена та існує подія з назвою "Some Event".

**Test Steps:**

| Step | Action | Data | Expected Result |
|:-----| :--- | :--- | :--- |
| 1    | Натиснути на іконку пошуку (лупу) на панелі керування подіями. | - | З'являється текстове поле для вводу пошукового запиту. |
| 2    | Ввести в поле пошуку частину назви події. | `So` | Список подій динамічно відфільтровується. Відображаються всі події, що містять "So" у назві (включно з "Some Event"). |
| 3    | Дописати назву події повністю. | `Some Event` | Список подій оновлюється. Відображається лише та подія (або події), назва якої повністю відповідає введеному тексту "Some Event". |


### Test Case ID: 3
**Title:** Перевірка можливості додати відповідь на коментар іншого користувача

**Priority:** Medium

**Preconditions:**
1. Користувач успішно авторизований у системі GreenCity.
2. Користувач знаходиться на сторінці подій (Events).
3. У системі існує подія, яка містить щонайменше один коментар від користувача.

**Test Steps:**

| Step | Action                                                                            | Data | Expected Result                                                                                                                                                    |
| :--- |:----------------------------------------------------------------------------------| :--- |:-------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 1 | Натиснути на кнопку "More" картки події, яка містить коментар іншого користувача. | - | Відкривається сторінка з детальною інформацією обраної події. Внизу сторінки відображається блок з коментарями.                                                    |
| 2 | Знайти коментар іншого користувача та натиснути кнопку "Reply".                    | - | З'являється текстове поле для вводу відповіді. Кнопка підтвердження "Reply" є неактивною.                                                                          |
| 3 | Ввести валідний текст у поле для відповіді.                                       | `Дякую за корисну інформацію!` | Кнопка підтвердження "Reply" стає активною.                                                                                                                        |
| 4 | Натиснути активну кнопку "Reply".                                                 | - | Новий коментар-відповідь візуально відображається під батьківським коментарем.                                                                  |

### Test Case ID: 4
**Title:** Перевірка відмови у завантаженні зображення у непідтримуваному форматі до коментаря

**Priority:** High

**Preconditions:**
1. Користувач успішно авторизований у системі GreenCity.
2. Користувач знаходиться на сторінці подій (Events).
3. У системі створена та існує щонайменше одна подія.
4. На локальному пристрої користувача підготовлений тестовий файл зображення у форматі `.avif`.

**Test Steps:**

| Step | Action                                                                                    | Data                                          | Expected Result                                                                                                                                                                                                                        |
| :--- |:------------------------------------------------------------------------------------------|:----------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 1 | Натиснути на кнопку "More" на картці будь-якої події.                                     | -                                             | Відкривається сторінка деталей обраної події. Внизу сторінки відображається поле для створення нового коментаря.                                                                                                                       |
| 2 | Ввести валідний текст у поле створення коментаря.                                         | `Дивіться, які класні фотки з івенту вийшли!` | Кнопка відправки коментаря стає активною.                                                                                                                                                                                              |
| 3 | Натиснути на іконку завантаження зображення під текстовим полем.                          | -                                             | Відкривається область для завантаження файлу.                                                                                                                                                                                          |
| 4 | Натиснути на посилання "Browse" та обрати файл у форматі `.avif` з локального комп'ютеру. | `event_image.avif`                            | Зображення не завантажується. Область завантаження та текст з інформацією про допустимі формати підсвічуються червоним кольором.                                                                                                       |
