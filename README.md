# Тестування та автоматизація сторінки подій проєкту GreenCity 🧪🤖

## 📌 Опис проєкту
Цей репозиторій створено в рамках виконання практичного домашнього завдання з курсу тестування програмного забезпечення (SoftServe Crash Course: Test Automation & Quality Control).

У цьому проєкті міститься аналіз функціональності сторінки подій веб-застосунку GreenCity. Він включає набір ручних тест-кейсів (включно з позитивними та негативними сценаріями) у форматі `.md`, а також автоматизовану реалізацію за допомогою **Python**, **Selenium WebDriver** та вбудованого модуля **unittest**.

## 🔗 Посилання на сторінку, що тестується
[GreenCity Events Page](https://www.greencity.cx.ua/#/greenCity/events)

## 🔐 Безпека та налаштування середовища
Для проходження автотестів необхідна авторизація на платформі. З міркувань безпеки реальні облікові дані приховані за допомогою змінних оточення.

Щоб локально запустити тести, виконайте такі кроки:
1. Створіть файл з назвою `.env` у кореневій директорії проєкту.
2. Додайте до нього свої тестові дані у такому форматі:
   ```text
   TEST_EMAIL=ваша_тестова_пошта@gmail.com
   TEST_PASSWORD=ваш_тестовий_пароль
   
## ⚙️ Інструкція запуску тестів
1. Переконайтеся, що на вашому комп'ютері встановлено Python (версії 3.x).
2. Завантажте всі необхідні залежності з файлу `requirements.txt`, виконавши команду в терміналі:
   ```bash
   pip install -r requirements.txt
   ```
3. Для запуску всіх автоматизованих тестів виконайте таку команду з кореневої директорії проєкту:
   ```bash
   python -m unittest discover tests
   ```

## 📂 Структура репозиторію
* `README.md` — інформація про проєкт, налаштування та інструкції.
* `requirements.txt` — список бібліотек, необхідних для запуску автотестів (зокрема, `selenium` та `python-dotenv`).
* `test-cases/events-page-tests.md` — документ із детально описаними ручними тест-кейсами.
* `tests/test_events_page.py` — файл із написаними автоматизованими UI-тестами.
